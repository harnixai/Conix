# 工作台

## 三块

```
╭ 对话区 ─────────────────────────╮╭ 会话 │ 流程 │ 作业 ───────╮
│ 顶部面板（goal / todo / 运行进度）││ 右上：列表               │
│ 转录                             │├──────────────────────────┤
│ 输入框                           ││ 右下：选中项的拆分        │
╰──────────────────────────────────╯╰──────────────────────────╯
```

**选中即切换**：右栏选中一个带会话的东西（会话、子 Agent、运行、站），左边就切到它的对话。流程定义、作业
本身没有会话，选中它们左边不动，详情在右下。

## 全局键位

| 键 | 作用 |
|---|---|
| `Ctrl+G` | 在对话区、右上、右下之间切换焦点 |
| `Ctrl+N` | 换到下一个标签（会话 → 流程 → 作业） |
| `Ctrl+B` | 窄屏时在左右两栏之间切换 |
| `Ctrl+R` | 跳到下一处等你处理的地方（提问、等确认的站、失败的作业） |
| `Ctrl+O` | 看完整转录 |
| `Ctrl+T` | 收起 / 展开顶部面板 |
| `Ctrl+C` | 打断正在跑的一轮（连按两次退出） |
| `Ctrl+X` | 退出（问后台运行还是停掉） |
| `Ctrl+H` / `F1` | 帮助：当前位置所有可用的键；`Tab` 或 `Ctrl+N` 翻到「样例」页：内置的流程包（装没装、怎么装、怎么起）与作业在会话里怎么说 |

键位都可以改，见 [配置](config.md#keybindingsjson)。

## 对话

- `Enter` 发送；`Shift+Enter` / `Alt+Enter` / `Ctrl+J` 换行；`Shift+Tab` 切权限模式。
- 正在跑一轮时再发是**插话**，会在下一步送到模型。
- **`@` 提及文件**：输入 `@` 后补全项目里的文件（跟着 `.gitignore`），`Tab` 填入路径。
- **回滚**：输入框为空时连按两次 `Esc`，列出能退回去的轮。选一轮退回到它之前，那句话放回输入框改了
  再发：`Enter` / `1` 撤对话与文件，`2` 只撤对话，`3` 只撤文件。只回滚文件工具的写，`Bash` 的副作用不回滚。
- **复制**：`Tab` 进转录，`[` `]` 选一块，`y` 复制它（没选就是最近一次回复）；`/copy` 同样。经 OSC 52
  送到终端剪贴板；终端不支持时 `/mouse` 关掉鼠标捕获，用终端自己的拖选。

## 斜杠命令

| 命令 | 作用 |
|---|---|
| `/new` | 新会话（第一句话发出时才建） |
| `/rename <名字>` | 改当前会话的名字 |
| `/model [名字]` | 不带参数弹出选择框，列出各 provider 的模型 |
| `/goal <目标>` | 给当前会话设一个 goal |
| `/btw <问题>` | 侧问：分叉出一个会话问，不打断当前的 |
| `/trust [off]` | 信任这个项目：读它自己的设置、流程与作业定义 |
| `/notify` | 发一条测试通知 |
| `/doctor` | 自检 |
| `/copy` | 复制最近一次回复 |
| `/events` | 最近的事件与命令 |
| `/mouse` | 开关鼠标捕获 |
| `/quit` | 退出 |

## 会话标签

上半是人发起的会话（新建的、分叉的）；流程、作业开出来的会话从流程、作业标签进。

| 选中的行 | 键 |
|---|---|
| 会话 | `Enter` 打开 · `r` 改名 · `x` 关闭 · → 展开 goal 与 todo |
| goal | `Enter` 修改 · `p` 暂停 / 恢复 · `x` 清除 |
| `▸ 已关闭 (n)` | → / `Enter` 展开 |
| 已关闭的会话 | 选中只读地看 · `o` 重新打开 · `d` 删除（转录连同子 Agent 一起删，删了就没了） |

下半是选中会话的拆分树：子 Agent（`◆`）与任务（`$` shell、`◉` 监视器、`λ` 程序、`⚙` MCP），选中哪个
左边就切到哪个；`m` 给子 Agent 发消息，`s` 停止。
