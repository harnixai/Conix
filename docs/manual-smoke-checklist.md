# 真终端冒烟清单

改了渲染、事件循环、终端外壳之后，在真终端里逐项过一遍：这些东西单元测试验不了。
阶段 2 的验收要求在四种环境里各过一遍：一个 macOS 终端（iTerm2 或 Terminal.app）、tmux、
ssh 到 Linux、Linux 物理控制台或尺寸固定的终端。

```sh
cargo build -p conix
./target/debug/conix --mock                 # 演示 demo；测试场景用 --mock m03-tools 等
./target/debug/conix                        # 真实实例：在一个项目目录里运行
```

## 1. 启动与终端

- [ ] 启动时窗口被请求调到 160×45；终端不支持时按原尺寸显示；退出后恢复原尺寸
- [ ] 在 tmux 里不发尺寸请求（窗口不变）
- [ ] `~/.conix/conix.yaml` 不存在时被生成；改 `ui.theme.preset: aqua` 后主色变水蓝；写错一项时底栏报出来、程序照常起来
- [ ] 中文、emoji、制表符对齐正确，没有错位或残影
- [ ] 拖动窗口改尺寸：宽 ≥ 120 两栏、80–119 单栏、< 60 显示"终端太小"，底栏始终有 `^G 切块 · ^N 标签 · ^B 切栏 · ^X 退出 · ^H 帮助`

## 2. 实例

- [ ] 实例选择是屏幕中间的小框，新建在第一行，上下键滚动，鼠标单击选中、双击接入
- [ ] 接入被占用的实例要二次确认；`conix --mock default list --all` 列出四种状态

真实实例（第一次执行新编出的二进制，macOS 要先扫描，可能卡十来秒）：

- [ ] 在项目目录里运行 `conix`：没有实例就新建（名字取目录名）并接入；退出选"后台运行"后 `conix list`
      还在、接入者一栏空了；再运行 `conix` 直接接回，之前的会话都在
- [ ] `conix stop <名字>` 之后再在这个目录运行 `conix`，拉起的是原来那个实例，不是 `<名字>-2`
- [ ] 另开一个终端运行 `conix`：提示被占用；选强制接入后，前一个终端显示"被踢"，按任意键可再接回
- [ ] 关掉接着实例的终端窗口（不是退出 TUI）：实例还在，`conix` 能接回
- [ ] 没有凭据时说一句话：转录里显示 `no_credentials` 的错误，界面不卡
- [ ] 有凭据时：流式回答、工具块、权限询问（允许 / 本会话允许 / 拒绝）、AskUserQuestion 的选项、
      子 Agent 出现在会话树、TodoWrite 进 Goal & Todo、`/goal`、`/btw`、`/model`
- [ ] 作业标签 `n`：话头"新建一个作业："进了当前会话（或草稿）的输入框；让它建一个每分钟跑一次的作业，
      作业出现在列表里；"停用 #1"这样按序号说也行；选中作业按 `m` 放话头，说"立即跑一次"；触发记录里有结局和用量；
      让它 `work_list` / `work_show`，读得到那次触发的报告
- [ ] 流程：在会话里让它建一个一站的小流程并启动一次运行；运行在流程标签里跑完；运行没结束时让它改这个
      流程，被拒并列出运行，右下显示 🔒

## 3. 对话区（对照 Claude Code）

- [ ] 输入框只有上下两条横线，多行时自动长高；Shift+Enter（或 ^J / `\` 加 Enter）换行
- [ ] `/` 补全、`!` 命令模式、空输入框按 `?` 打开帮助、Shift+Tab 切权限模式
- [ ] 流式回答时状态行 `✻` 动画、秒数、↓ tokens；输入框下显示 `esc 中断`；Esc 中断
- [ ] 工具块 `⏺` / `⎿`、结果折叠与 `ctrl+o 展开`；^O 进转录并展开成详细、再按回输入框收回，转录里 `o` 切详略、`[` `]` 选块
- [ ] markdown：标题、列表、表格、引用、代码块语法高亮（「Conix 展示」会话）
- [ ] 审批框：数字 / 上下键 / 鼠标选，Esc 拒绝；正在打字时审批框不抢键盘
- [ ] 粘贴超过 10 行显示 `[粘贴了 N 行]`，提交时展开（需要终端支持 bracketed paste）

## 4. 右栏

- [ ] 会话标签：上下键选主 Agent，左边对话区跟着切；→ 展开 goal / todo；Tab 进下半任务树，选子 Agent 左边跟着切，Esc 回到上一层
- [ ] 对话区顶部面板：有 goal / todo 的会话打开、没有的没有；下沿右边 ^T，收起后只剩标题线，点标题线也收放；面板不拿焦点，超过 10 行时滚轮滚动
- [ ] 会话标签第一行是新建会话；列表里没有流程、作业开出来的会话；焦点在下半时标签头仍是选中色
- [ ] 启动是新会话草稿，不输入就不建会话；^N 换到会话标签回到最近活跃的会话；选中项按对象记，新会话进来不漂移；有焦点那块的选中行橙底、另一块暗一档
- [ ] 流程标签：选流程即展开运行，左边不动、右下是流程设计；选运行左边是主会话、面板是运行进度，下半是整棵树（主会话、各站、子 Agent 与任务，带模型），各站不缩进、按进展上色；选「设计」站切到它的独立会话；站上按 `m`，话头写明运行与站，以前的 `c` `a` `f` `r` `t` `p` `x` 不再有反应
- [ ] 作业标签：选作业左边不动，右下是定义、执行情况与统计、触发记录；流程作业的流程 Enter 跳过去；选触发记录左边跳到那次的会话；→ 展开简单作业的一次触发，是那个会话的任务树；流程作业的触发 Enter 跳到流程标签里那次运行
- [ ] 在家目录运行 `conix`：进的是 `~/Documents/Conix`（没有就建）；`conix new --project ~` 被拒
- [ ] ^G 在输入框 → 右上 → 右下之间转，^N 轮换标签后 ^G 到它的右下；^R 依次跳到等你处理的地方；`/` 过滤；`/events` 事件日志
- [ ] 鼠标：点标签头、点列表、滚轮滚动所在区域、拖动两栏之间的边框调比例；`/mouse` 把鼠标交还终端后能用终端原生选择

## 5. 退出

- [ ] Ctrl+X 弹出退出框：后台运行 / 直接退出 / 返回；鼠标也能点
- [ ] 连按两次 Ctrl+C、连按两次 Ctrl+D 也弹出同一个框
- [ ] 退出后终端恢复正常（光标、回显、鼠标、备用屏），没有残留的转义序列

## 6. 环境特有

- [ ] tmux：鼠标、颜色正常；`set-clipboard on` 时 OSC 52 能写剪贴板（P1）
- [ ] ssh：延迟下按键不丢，画面不撕裂
- [ ] 物理控制台 / 固定尺寸：单栏下 ^B 切过去切得回来，^G 转到另一栏时自动换栏，底栏那几项始终可见
